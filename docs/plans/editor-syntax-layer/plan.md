# The source as the only truth, and the syntax layer of a ProseMirror editor

## Why

Settle's editor moves to ProseMirror with the syntax characters kept in the
text, and this crate becomes the one syntax that both the editor and Settle's
index read; but the crate treats canonical output as the goal of writing, and
offers no WebAssembly build, no inline-only parse, and no way back from a leaf
to its source. This plan makes the source text the only truth, so a parsed
document writes back every unchanged block byte for byte, and gives the
editor the entry points it calls.

- Scope: the kept source and source reuse in `to_markdown`, `parse_inline`,
  `inline_source`, and a new zero-dependency `markdown-syntax-wasm` crate with
  a thin JS wrapper in the same repository.
- Decisions 0007, 0008, and 0010 are superseded by 0012, 0013, and 0014.
- Breaking: `to_markdown` on a parsed document returns its source where
  nothing changed, and `Document { meta, children }` no longer compiles.
- Largest risk: the read-back of a rendered block beside reused ones; the
  spike found none in 4429 simulated edits.

## What changes

### Parsing
- `public-api` › Inline parse: added
- `public-api` › Inline source of a leaf block: added
- `public-api` › Parsed documents keep their source: added
- `public-api` › One syntax: modified — `parse_inline` is the second entry
  point, reading the same syntax
- `public-api` › Output verbs on Document: modified — adds `inline_source`,
  `source`, and `without_source`; its scenario returns the source
- `public-api` › Hand construction: modified — adds `Document::new`
- `untrusted-input-cost` › Linear time: modified — covers `parse_inline`,
  `inline_source`, and writing with a source

### Writing
- `serialization` › Unchanged source is kept: added
- `serialization` › Canonical output: modified — applies to the nodes a write
  does not take from the source
- `serialization` › Round-trip stability: modified — compares documents
  written without their source
- `serialization` › No HTML filtering or style preservation: modified — the
  only recovered spelling is unchanged source
- `serialization` › Rendering only: modified — the kept source is an input
- `serialization` › Serialize options, Tree comparison, Text is written as
  recorded, Table cells encoded by one rule, Container lines take their full
  prefix, Heading soft breaks, ATX content ending in a closing-like run,
  Values are encoded by rule, Code spans written from their value, Breaks and
  item content placed by rule, Links and autolinks written in their recorded
  form: modified — their scenarios write the parsed document without its
  source
- `block-syntax` › Block directives: modified — the same, for its
  serialization scenario
- `validation` › Shapes that cannot be written: modified — the same, for its
  hard-line-break scenario

### WebAssembly binding
- `wasm-binding` › Build: added
- `wasm-binding` › Parse from JavaScript: added
- `wasm-binding` › UTF-16 offsets: added
- `wasm-binding` › Inline parse and inline source from JavaScript: added
- `wasm-binding` › Write from JavaScript: added
- `wasm-binding` › Malformed trees: added
- `wasm-binding` › Released memory: added

### Outside the specs
- Decisions 0012 "Parse entry points and one normative syntax" (supersedes
  0007), 0013 "The source is the only truth" (supersedes 0008), and 0014
  "Test evidence" (supersedes 0010).
- The repository becomes a Cargo workspace whose root package is the core
  crate and whose one member is `wasm/`. CI builds the member for
  `wasm32-unknown-unknown` and runs its JS tests.
- `docs/overview.md`, `CLAUDE.md`, and `README.md` describe the kept source,
  the workspace, and goldens generated by a command and read in review.

## Out of scope
- Publishing `markdown-syntax-wasm` to crates.io or an npm package to npm —
  Settle uses it as a git or path dependency until the binding settles; the
  core crate's changes ship with its next release.
- The block model built for the editor (flat list items, blank lines as
  content, every block spelling recorded, source reused per node), and `#tag`
  in the syntax — the second batch, planned after studying
  meowdown's source.
- A Settle decision replacing its 0001 (CodeMirror 6) — Settle's repository.
